# docs/prd/

This directory contains Product Requirements Documents (PRDs) for Atlas.

## Purpose

A PRD defines **what** to build and **why**, from the product perspective. It includes:

- Problem statement and user need
- Success metrics and acceptance criteria
- Scope (in and out of scope)
- User stories at an epic level
- Dependencies and risks

## Naming Convention

```
PRD-<id>-<short-title>.md
```

Example: `PRD-001-ai-inbox.md`
