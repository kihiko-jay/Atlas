# docs/tas/

This directory contains Technical Architecture Specifications (TAS) for Atlas.

## Purpose

A TAS is the detailed engineering blueprint for a major system component or cross-cutting concern. It translates high-level architectural decisions into specific technical designs:

- Component diagrams and data flow diagrams
- Database schema design
- API interface definitions
- Sequence diagrams for critical flows
- Non-functional requirements (performance targets, SLAs)
- Security model
- Deployment topology

## Naming Convention

```
TAS-<id>-<component-name>.md
```

Example: `TAS-001-identity-domain.md`
