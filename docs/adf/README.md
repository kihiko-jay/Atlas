# docs/adf/

This directory contains the Atlas Architecture Decision Framework (ADF).

## Purpose

The ADF establishes the architectural principles, constraints, and quality attributes that guide all technical decisions in Atlas. It is the foundation against which Architecture Decision Records (ADRs) are evaluated.

## Contents

- **Principles** — non-negotiable architectural values (e.g., domain isolation, testability)
- **Constraints** — hard limits (e.g., technology choices, regulatory boundaries)
- **Quality Goals** — ranked quality attributes (e.g., maintainability over performance where trade-offs exist)
- **Architectural Patterns** — approved patterns and their appropriate contexts

## Documents

> The ADF is populated as the architecture review process is formalized. Nothing is documented here yet.
